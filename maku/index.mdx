An interactive browser host for the Maku engine: pick a tutorial
or translated demo card, run it in wasm, edit the card source, adjust host
channel bindings, and read the tutorial text alongside the simulation.

[**Open the tutorial host →**](./play.html)

## Documentation

The [reader](./tutorials.html) keeps the guided tutorials and reference
material in separate sections. The reference section includes the language,
host API, renderer API, supported Rust API, and native-player documentation.

The tutorial text is rendered by this site, while the simulation host,
bindings panel, card manifest, and wasm runtime are shared with the engine
repository's standalone web demo.

[Source on GitHub](https://github.com/mlegls/maku)
